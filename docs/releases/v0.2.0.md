# AI Local Hub v0.2.0

## What's new

- **Native Rust backend:** Replaced the bundled Bun/Node desktop manager and MCP workers with native Rust processes (Axum, rmcp, Tokio). React/Vite UI and Tauri desktop shell remain.
- **Improved desktop layout:** Logs now stay within the window height and scroll independently. Instance list also scrolls independently on desktop.
- **Better interaction:** Pointer cursors on buttons, dropdowns, dialogs and clickable items; folder browser navigation now selects absolute child paths.
- **Dev build reliability:** Rust build/test scripts locate `rustc` alongside the chosen Cargo toolchain, even when the shell PATH is incomplete. `yarn dev` uses a separate debug config to avoid interfering with installed instances.
- **MCP and process hardening:** Bounded shell output, execution concurrency and large-file operations; improved shutdown handling, Host/Origin checks, symlink edits and configuration-save rollback.
- **Release verification:** Integration/regression tests and DMG integrity checks guard native binaries before packaging.

## macOS downloads

- Apple Silicon (M1/M2/M3/M4): `AI.Local.Hub_0.2.0_aarch64.dmg`
- Intel Mac: `AI.Local.Hub_0.2.0_x64.dmg` (cross-compiled; not tested on physical Intel hardware)

Install: open the appropriate DMG and drag **AI Local Hub.app** into Applications. Quit the previously installed version first; doing so will disconnect active MCP sessions until restarted.

**Important:** These installers are unsigned and not notarized. macOS may require **System Settings → Privacy & Security → Open Anyway** for trusted downloads.

**Security:** Connected clients have filesystem/shell permissions of the local OS account; workspace is not yet a sandbox. Connect trusted AI clients only.

**Validation:** Local Rust MCP/manager and hardening tests and TypeScript reference regression tests passed; Apple Silicon desktop builds and DMG verification are performed before publishing. Remote tunnel handshakes and other OS/device configurations are not exhaustively validated.

AI Local Hub is an independent project, not an official OpenAI application.
