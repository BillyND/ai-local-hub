# AI Local Hub v0.4.3

## What's new

- **Fast native release pipeline:** build the React UI once, then package macOS, Windows and Linux installers in parallel on native GitHub Actions runners.
- **Cross-platform installers:** release builds produce macOS DMGs, Windows MSI/NSIS installers, and Linux AppImage/DEB packages.
- **Local TypeScript LSP precedence:** project-local `typescript-language-server` is preferred over a global native TypeScript LSP binary.
- **Windows build cleanup:** platform-specific executable permission code no longer emits an unused-mutability warning on Windows.
- **Bash timeout stability:** zero-window auto-background responses no longer include a racy partial output preview.

## Downloads

The GitHub release attaches installers for:

- Apple Silicon macOS: `aarch64.dmg`
- Intel macOS: `x64.dmg`
- Windows x64: `.msi` and `.exe`
- Linux x64: `.AppImage` and `.deb`

Installers are unsigned and not notarized by default. The app grants connected AI clients the filesystem and shell permissions of the local OS account; connect only trusted clients.
