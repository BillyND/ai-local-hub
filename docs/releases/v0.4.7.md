# AI Local Hub v0.4.7

## What's new

- **macOS x64 release reliability:** the Intel macOS installer now builds on the available macOS runner by cross-targeting `x86_64-apple-darwin`, avoiding long `macos-13` queue starvation.
- **Windows installer build fix:** invoke the Tauri CLI through the current Node executable instead of the generated `tauri.cmd` shim, avoiding Windows shell quoting and PATH failures in GitHub Actions.
- **Linux installer build fix:** CI installs AppIndicator and XDO development packages required by Tauri's Linux tray-related dependency graph.
- **Cross-platform installers:** release builds produce macOS DMGs, Windows MSI/NSIS installers, and Linux AppImage/DEB packages.

## Downloads

The GitHub release attaches installers for:

- Apple Silicon macOS: `aarch64.dmg`
- Intel macOS: `x64.dmg`
- Windows x64: `.msi` and `.exe`
- Linux x64: `.AppImage` and `.deb`

Installers are unsigned and not notarized by default. The app grants connected AI clients the filesystem and shell permissions of the local OS account; connect only trusted clients.
