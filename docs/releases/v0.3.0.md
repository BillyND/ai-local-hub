# AI Local Hub v0.3.0

## What's new

- **Per-instance MCP tool groups:** choose `core`, `ast`, `lsp`, and `ls` groups independently for each instance; disabled tools are removed from MCP discovery and rejected when called.
- **Native build reliability:** Tauri commands inherit the Rust toolchain environment even when `cargo` is not on the shell `PATH`.
- **Underscore-only macOS artifact names:** generated app and DMG names contain no spaces.
- **Release verification:** native binaries, app bundle, and DMG integrity are checked before publishing.
- **Coding-tool parity:** continued oh-my-pi alignment across hashline editing, file/search tools, bash jobs, AST tools, and LSP actions.

## macOS downloads

- Apple Silicon (M1/M2/M3/M4): `AI_Local_Hub_0.3.0_aarch64.dmg`
- Intel Mac: `AI_Local_Hub_0.3.0_x64.dmg`

Install: open the appropriate DMG and drag **AI_Local_Hub.app** into Applications. Quit the previously installed version first; doing so disconnects active MCP sessions until restarted.

**Important:** These installers are unsigned and not notarized. macOS may require **System Settings → Privacy & Security → Open Anyway** for trusted downloads.

**Security:** Connected clients have filesystem and shell permissions of the local OS account; the workspace is not a sandbox. Connect only trusted AI clients.

**Validation:** Local MCP, manager, hardening, Rust unit, vendored parity, Apple Silicon desktop, and DMG verification checks pass. Intel output is cross-compiled on Apple Silicon and requires testing on a physical Intel Mac before claiming native Intel runtime validation.

AI Local Hub is an independent project, not an official OpenAI application.
