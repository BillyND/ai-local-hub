# AI Local Hub v0.5.0

## What's new

- **Automatic updates:** the desktop app checks for a new release 10 seconds after launch and every 6 hours, then shows a system notification and an in-app banner. The **Updates** button holds the **Install updates automatically** switch (on by default): when on, the app downloads, verifies, installs and restarts by itself; when off, nothing installs until **Update and restart** is clicked.
- **Instances come back after an update:** instances that were running or starting before an update restart start again in the new version.
- **Signed updates:** every update package is signed in the release workflow and verified by the app before it installs.
- **Faster quit:** quitting the desktop app no longer waits 20 seconds for the manager to stop while the window is open.
- **Documents in the `read` tool:** `read` extracts text from PDF, DOCX, PPTX (per slide) and XLSX files, so MCP clients can see inside them. Scanned PDFs without a text layer report a clear error.

## Upgrading

Version 0.4.8 and older have no updater: install this version by hand once. Later versions arrive automatically.

## Downloads

The GitHub release attaches installers for:

- Apple Silicon macOS: `aarch64.dmg`
- Intel macOS: `x64.dmg`
- Windows x64: `.msi` and `.exe`
- Linux x64: `.AppImage` and `.deb`

It also attaches the signed update packages and `latest.json` that installed apps use to update.

Installers are unsigned and not notarized by default. The app grants connected AI clients the filesystem and shell permissions of the local OS account; connect only trusted clients.
