# AI Local Hub v0.6.0

## What's new

- **External MCP server gateway:** each instance can run trusted stdio MCP servers and re-expose their tools through the same local MCP endpoint and OpenAI tunnel, with tool allowlists, timeouts, restart supervision and secret masking.
- **More reliable process lifecycle:** shell commands, language servers and other child processes are stopped as whole process groups during cancellation, timeouts, worker shutdown and manager shutdown.
- **Stronger crash isolation:** PDF extraction runs in a bounded child process, blocking file/tree tools honor cancellation and time limits, and malformed or oversized input is contained to the affected request.
- **Shared language-server pool:** concurrent sessions reuse language servers safely, while detached starts, request timeouts and stderr handling avoid leaked or half-started processes.
- **Improved manager lifecycle:** shutdown drops stale connections, folder listing no longer blocks async workers, SIGTERM is handled cleanly, and offline starts can use the newest verified tunnel-client already in the cache.
- **Desktop quit reliability:** quitting through the desktop UI, tray or last window no longer blocks the UI thread while the manager stops.
- **Updated MCP tooling:** search, AST, LSP, document extraction and cancellation paths receive bounded concurrency, output limits and clearer failure behavior.

## Downloads

The GitHub release attaches installers for:

- Apple Silicon macOS: `aarch64.dmg`
- Intel macOS: `x64.dmg`
- Windows x64: `.msi` and `.exe`
- Linux x64: `.AppImage` and `.deb`

It also attaches the signed update packages and `latest.json` that installed apps use to update.

Installers are unsigned and not notarized by default. The app grants connected AI clients the filesystem and shell permissions of the local OS account; connect only trusted clients.
